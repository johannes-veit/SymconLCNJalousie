# Veröffentlichungs-Checkliste

- [ ] GitHub-Repository ist öffentlich.
- [ ] `main` enthält alle vorbereiteten Dateien.
- [ ] GitHub Action **Validate Symcon module** ist grün.
- [ ] Repository-URL im Symcon Module Control eingetragen.
- [ ] Konfigurator und Geräteinstanz lassen sich anlegen.
- [ ] Alle Pflichtfelder im Modulmenü sind auswählbar.
- [ ] TS-Belegung bleibt bis zur Busprüfung unbestätigt.
- [ ] Lokale LCN-Bedienung funktioniert ohne Symcon.
- [ ] Relais AUF und AB können nie gleichzeitig aktiv sein.
- [ ] STOP, Endlagen und Referenzfahrt wurden beaufsichtigt getestet.
- [ ] Erst danach Tag `v0.1.0` und GitHub Release erstellen.
