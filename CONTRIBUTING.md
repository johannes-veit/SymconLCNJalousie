# Mitwirken

1. Für Änderungen einen neuen Branch anlegen.
2. Änderungen lokal prüfen: `python tests/validate_repository.py`.
3. Keine realen Symcon-IDs, Zugangsdaten oder private Busprotokolle committen.
4. Motor- und Endlagentests im Änderungsbericht dokumentieren.
5. Pull Requests müssen die Sicherheitsprinzipien beibehalten: Verriegelung in LCN-PRO, reale Relaiszustände als einzige Bewegungsquelle, keine künstlich gesetzten Relaiszustände.
